# Gan 2026 Experiment Docs

This directory holds human-readable Gan 2026 experiment history. Use it for
predeclarations, protocols, run reports, validation-surface readouts, and
iteration notes.

Buckets:

- `agentic/`: Agentic component and KG-grounded experiment plans/readouts.
- `architecture_reset/`: Reset-phase manifests, plans, and completed-task notes.
- `baselines/`: Baseline and smoke-run records.
- `component_mechanics/`: Component-control, candidate, ambiguity, projection,
  and LLM-mechanics experiment records.
- `frozen_test/`: Locked-test protocols and aggregate holdout readouts.
- `reliability/`: Confidence, gating, scorecard, and robustness workflow docs.
- `rq_series/`: Numbered research-question protocols and answers.
- `selective_verifier/`: Selective verifier and safety-floor experiments.
- `validation_test_gap/`: Validation-to-test gap protocols and staged actions.
- `validation750/`: Validation750 verifier, null-reduction, and slice readouts.

Keep paper-facing synthesis and durable interpretation in `docs/research/gan2026/`.
