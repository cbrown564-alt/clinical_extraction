being iterated:

- `key_entities/`: Multi-entity structured prompt and integration readouts.
- `diagnosis/`: Diagnosis specialists, verifiers, decomposers, reconcilers, and
  gates.
- `seizure_frequency/`: SeizureFrequency verifiers and state adjudicators.
- `medication_investigations/`: Medication and investigations verifier runs.
- `predeclarations/`: Pre-run protocols and audit declarations.

Keep durable architecture strategy, gold/scoring principles, and broad synthesis
in `docs/research/` or `docs/design/`.
