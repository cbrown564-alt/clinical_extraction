# Experiment Docs

This directory holds human-readable experiment records: predeclarations, pilot
reports, dev-surface readouts, ablation summaries, and short iteration notes.

Use this folder when the document is mainly a run record. Keep raw outputs,
scripts, JSON/JSONL files, and generated scorecards in the repository-level
`experiments/` directory.

Suggested layout:

- `exectv2/`: ExECTv2 run reports and predeclarations.
- `gan2026/`: Gan 2026 run reports and predeclarations.
