The model collects. Rules shape the form.

The proposed method translates clinic letters into structured facts in a designed form, with quoted source text. A model collects the facts and evidence. Recorded rules then shape those facts into the required form. The two public golds are the forms used for evaluation; they are not the task.

What this view establishesIt shows how the proposed method is organised and what its traces record. It does not prove that every stage is necessary, clinically safe, or transferable unchanged to another task. Tables cite Grok so the story stays on the method.

One shared sequence, two task-specific endings

The package also exposes rules-only and model-only baselines. The proposed method is the model plus recorded rules. Those mappings can be replayed on saved model output without a new call.

1. Letter: source clinical statements
2. Model: structured facts and quoted source text
3. Rules: normalise, constrain, verify, and record changes
Gan: one current seizure-frequency label
ExECT: a set of supported clinical facts

What the model does

The model collects the facts and quoted source text from flexible language.

  • Find relevant clinical statements.
  • Interpret time, reference, and uncertainty.
  • Collect structured events or findings.
  • Keep supporting text in the object.

What recorded rules do

The rules shape those facts into the required form and record every clinical change.

  • Render allowed labels and attributes.
  • Apply recorded task policies.
  • Check evidence and permitted conflicts.
  • Expose rescues, harms, abstentions, and no-ops.

Gan commits to one answer

The deterministic sequence resolves a proposed frequency, reconciles it with the selected span, chooses among competing readings, and renders one canonical label.

  1. Resolve the model's event representation.
  2. Reconcile the label with selected evidence.
  3. Apply recorded clinical selection rules.
  4. Handle seizure-free intervals and render the result.

ExECT assembles an inventory

The deterministic sequence projects model events into four clinical families, applies family-specific checks, and returns a coherent set of facts.

  1. Flatten model events into candidate mentions.
  2. Project and check family attributes.
  3. Apply Diagnosis, frequency, and Prescription rules.
  4. Require evidence and return the final inventory.

The trace is part of the result

A reviewer can follow a source statement through the component that changed it. This supports inspection and replay; it does not guarantee correctness.

source evidence
The relevant text retained from the letter.
model ledger

final output
The submitted answer in the designed form. The gold is how this paper scores it.
