# Clinical Recovery Is the ExECTv2 Headline; Mention/CUI Projection Is an Artifact Layer

Date: 2026-06-18

For ExECTv2 we make clinical-fact recovery the per-entity headline (a `Clinical Recovery Headline`) and demote ExECT mention-phrase and CUI projection to a separately-credited artifact layer. The all-entity exact-phrase benchmark F1 is retired as the scoreboard because it is largely a target-construction artifact: item-level analysis shows 84% concept overlap but only 38% exact altitude, and an oracle that snaps phrases to gold only when entity+attributes already agree caps at F1 ~0.42. Chasing that number rewards reproducing annotation phrasing conventions, not clinical understanding.

Each entity's headline follows its kind. Decomposable entities (Prescription, Investigations, SeizureFrequency) take a `Clinical Component Score` headline; atomic-concept entities (Diagnosis, Onset, WhenDiagnosed, EpilepsyCause, BirthHistory) take a `Concept-Identity Headline` — concept + assertion attributes, scored source-entity-agnostically, with DiagCategory supplied by deterministic normalization. The `Concept Recovery Unit` splits coordinated compounds into atomic facts but collapses specificity hierarchies to the most-specific concept. SeizureFrequency uses `Frequency State Recovery` ({active-rate, seizure-free, unknown}, per seizure type, `unknown` a first-class TP) with exact counts as diagnostics. PatientHistory is demoted to a `Coverage-Diagnostic Entity` (heterogeneous, recall-bound). Prescription temporality, lacking any gold signal, is scored against the as-annotated gold with a one-way non-penalizing `Future Medication Diagnostic`.

Trade-off accepted: we lose direct comparability to the published per-item benchmark (the 0.87 target) in exchange for a headline that measures recovered clinical facts. The projection/CUI numbers are still reported, just beneath the headline, so the benchmark surface is recoverable when comparability is needed. This resolves the recurring gold-representation issues from the 2026-05-14 gold-label audit by classifying each as either clinical recovery (headline) or annotation-convention projection (demoted) rather than re-litigating them as bugs.
