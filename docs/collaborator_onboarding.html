What this repository is

Hybrid deterministic–LLM pipelines for extracting structured clinical data from unstructured epilepsy letters. The long-term goal is a reusable Python package; the active research combines a frozen single-label benchmark (Gan) with broad phenotyping (ExECTv2).

Modular breadth

Task-specific code under tasks/; reusable primitives in core/. Gan is the deep single-label surface; ExECT covers Dx, SF, Rx, Investigations.

Evidence-first evaluation

Intermediate schemas, evidence spans, row-level error artifacts, and predeclared frozen audits — not just final F1 numbers.

Rules as science

Deterministic behavior is categorized (general, clinical, task-specific, benchmark-format), testable, and ablatable — never hidden preprocessing.

Control plane

Live steering: PROJECT_STATUS.md → docs/plans/ACTIVE_ROADMAP.md → docs/THREAD_MAP.md. Structural truth lives in docs/canon/01–10.

Five Gan mechanism-level findings

LLM output must be candidates only. Direct note→label over-reads historical frequency. Evidence: 329 val rows regressed vs 26 recovered when using direct labeler.

Source-near events with evidence, kind, temporality suppress over-reading. Inspectable intermediate state is the key architectural move — not another prompt patch.

Most lift comes from disciplined replace with 3-trace agreement, not broad ensemble stacking. Safety floor gate v0: combined selective gate +8 test450 rows with 0 correct→wrong.

GPT-only reasoner −51 rows; GPT+DeepSeek −30; full 3-trace +21. V12 ceiling at 379/450 requires full corroboration stack.

Single-pass GEPA ~0.73 (mini) / ~0.65 (Qwen) vs hybrid v08 0.9155 on dev140 clinical_headline. Root cause is per-family: mostly gold multiplicity (Dx 93.5% H-inflated), not uniform producer recall gap.

Letter ingest

gan2026_split_v1 locked protocol. Validation ladder: 1 → 25 → 50 → 250 → 750 before holdout. Row quality and source artifacts preserved for evidence substring checks.

Structured events (LLM)

LLM emits source-near candidates: evidence span, kind (frequency/seizure_free/unknown), temporality, assertion. Must not parse counts, ranges, or scorer-facing labels — that is deterministic normalization's job.

Clinical selection

SelectedClinicalFact chooses the clinically relevant fact from a CandidateSet, or abstains. Selection precedence: C1 current positive rate supersedes coexisting seizure-free (ADR 0016).

Projection / render

Deterministic code expands phrases into parsed counts, time periods, canonical states, Gan label grammar. Evidence Trace Check (ADR 0014) is a canonical fourth stage — distinct from hybrid Verify vocabulary.

Purist / Pragmatic score

Compatible with author-provided evaluation code. Purist is strict; Pragmatic allows format tolerance. Holdout citation is aggregate-only — row-level inspection blocked.

Candidate producers

CandidateProducer proposes ClinicalFinding objects with entity, text, attributes, evidence, provenance. Frozen LLM/hybrid artifacts replay through JSONL adapters — v08 is behavior-preserving structural cleanup.

ClinicalFindingStore

Per-letter collection of raw and scored findings from all producers. Enables component-off ablation: dictionary (+0.019–0.029), residual semantic lens (+0.010–0.012), headline projection (+0.030–0.035) on full-200.

Entity lenses

EntityLens reconciles per entity: Diagnosis hierarchy/negation, SF state adjudication, Prescription regimen, Investigations result lenses. SF uses state_profile as primary metric for SF-family experiments (ADR 0037).

Finding views

Surface hierarchy: phrase_only → semantic → benchmark. clinical_headline is primary scoreboard. Benchmark F1 fuses three layers — never quote alone as extractor quality.

Attribution sidecar

Row-level FindingSource and ProvenanceEvent preserve producer ownership, deterministic actions, evidence status. Component evidence contract governs promotion.

The Wall vs gold-quality ceiling

Two disjoint mechanisms limit apparent F1. Narratives converge but live on different datasets and scoring surfaces.

Gan · The Wall

Confident over-reading

On binding residual rows, every forward-observable feature fails to separate withhold-to-unknown from emit-rate. Only hidden gold distinguishes them.

  • Irreducible residual: 11 val rows, 8/11 band_unknown
  • P2.1 semantic entropy flat → over-reading is confident
  • Self-confidence degenerate (99.2% one bucket)
  • External Risk AUROC 0.781 — strongest leg is cross-model agreement
ExECT · Gold-quality

Annotation multiplicity

Benchmark F1 fuses target representation, scorer design, and extractor output unit. Many "errors" are format fidelity or gold consolidation artifacts.

  • SF: metric counts per-type CUI; model consolidates clinically
  • Dx: gold lists multiple equivalent diagnoses; model merges
  • SF trap: rescoring under state_profile lifts without changing preds
  • Methods caveat: same-team adjudication — label internally adjudicated
Wall transfer (C3) — bounded

ExECT SF probe: 6/9 checks pass; External Risk AUROC 0.764; binding-slice abstention AUROC 0.676 (below 0.70 bar). Suggestive, not definitive — small-n slice.
