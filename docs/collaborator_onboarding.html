What we built

What this project does

Doctors write clinic letters in free text. We build software that turns those letters into structured fields a computer can use — seizure counts, diagnoses, drug names, test results. We do not ask a model to jump straight to the final answer; we split the work so each step can be inspected.

Track 1 — one label per letter

On synthetic letters, we extract seizure frequency only. The main lesson: extract facts first, then let rules choose the clinically current answer. Some hard cases still fail even when the model is confident — we call that limit The Wall (see Limits tab).

Track 2 — many fields per letter

On real de-identified letters, we extract a full epilepsy profile. The main lesson: a strict benchmark score can look much worse than clinical judgment because gold labels list facts differently than a clinician would consolidate them — we call that the gold-quality ceiling (see Limits tab).

Important limits

Why scores stop improving

Both tracks hit ceilings — but for different reasons. Start with the picture: one is a wall the model runs into; the other is a low ceiling on the scoreboard even when the clinical answer is fine. Do not mix up the two stories.

Track 1 · seizure frequency

Confident mistakes on ambiguous letters

The intuition: Imagine asking “how many seizures per month?” when the letter only describes vague past burden and “well controlled” today. A clinician would say unknown. Our model often outputs a specific band anyway — and looks confident doing it. Prompt tuning cannot punch through this wall.

Real pattern (illustrative letter)
“Had frequent seizures in childhood. Currently well controlled on medication with no reported events in clinic.”
Model output “~1 per month”

Confident — uncertainty metrics stay flat

Gold label Unknown

Only the hidden label tells you to abstain

Now the bars make sense: we are close to the wall, not far from perfect extraction.

Project vocabulary & metrics (peel back the onion)
  • Binding residuals: rows where only the hidden gold label tells you the model should abstain
  • P2.1: semantic entropy flat on residuals → over-reading is confident
  • 11 irreducible validation rows; external risk AUROC 0.781
  • ~84% is a research prior, not a tuning target
Track 2 · full profile

Scoreboard vs clinical judgment

The intuition: Imagine a room with plenty of headroom — that is clinical judgment on the extraction. But the benchmark scoreboard has a low ceiling: it expects facts listed exactly the way annotators encoded them. Merge two equivalent diagnoses into one row? Clinically fine. Strict matcher says wrong.

Side-by-side — two different ceilings

The Wall

Ambiguous letter → model commits a rate → ~84% cap. Fix: abstention research, not more prompts.

Gold-quality ceiling

Strict matcher → format/multiplicity gap → clinical review much higher. Fix: scoring surfaces, not model retraining alone.

Cross-track note (claim C3)

Early evidence suggests Track 1’s “confident mistake” pattern may appear in Track 2 seizure-frequency errors too — but abstention signals are not yet strong enough to act on automatically.
