# Documentation

Start with:

1. [project status](../PROJECT_STATUS.md);
2. [active roadmap](plans/ACTIVE_ROADMAP.md);
3. [retained evidence index](experiments/retained_evidence_manifest.md);
4. [paper claim status](canon/10_paper_provenance.md).

The folders have one purpose each:

- `canon/`: current summaries of the system, evidence, scoring, and paper claims;
- `design/`: current software and data decisions;
- `decisions/`: reasons for behavior that is still active;
- `experiments/`: reports selected by the retained evidence index;
- `reference/`: metric definitions and the naming guide;
- `research/`: the manuscript, thesis, annotation source, and cleanup record;
- `runbooks/`: repeatable procedures.

Historical plans and superseded reports remain available from Git history.
