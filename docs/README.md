The remaining folders have one purpose each:

- `canon/`: maintained architecture, evidence, scoring, and claim summaries;
- `design/`: current architecture and data decisions;
- `decisions/`: durable reasons for active behavior;
- `experiments/`: manifest-selected human-readable evidence;
- `reference/`: stable metric and vocabulary definitions;
- `research/`: manuscript, thesis, annotation source, and surgery owner;
- `runbooks/`: repeatable operational procedures.

Historical plans, candidate reports, row dossiers, and redirects are available
from Git history.
