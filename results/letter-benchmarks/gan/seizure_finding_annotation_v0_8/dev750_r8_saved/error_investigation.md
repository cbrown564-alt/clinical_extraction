This pairing is a source-location audit. A shared quotation proves that two unmatched findings refer to overlapping source text. It does **not** prove that the text contains only one clinical claim, that the gold is right, or that accepting the pair would be clinically sound. The 271 selected pairs are maximum-cardinality, one-to-one overlap pairs, breaking ties toward similar finding attributes. They involve 65% of all extras and 49% of all misses. At least one missed/extra quotation overlaps in 224 of 243 mixed-error letters. All 19 without byte-exact overlap were read separately in the full note; their classifications are in the index below. Another seven of these 19 express substantially the same clinical claim in different passages or nonidentical quotations. Four are related but have different scopes, and eight concern distinct claims.

The 271 pairs have nonexclusive scored differences: measurement value 109, period 104, event label 75, timing 43, measurement type 35 and seizure status 16. These are **differences observed**, not mutually exclusive causes. Individual rows often have several.

## What recurs

### 1. One source statement acquires several scoreable forms

Seizure freedom is frequently expressed as a last-event anchor, an interval of freedom, and a broad negative summary. The source may support more than one wording for the same state, while the exact object fields cannot match. In rows 4597, 4839, 7738 and 8224, the gold and R8 findings disagree on anchor versus duration, despite shared source evidence. In row 14949 the statement appears in separate passages, so a byte-overlap check alone misses the connection. The ideal annotation unit is **one absence claim for a given event scope and interval**, with one normalized interval or anchor representation and the original quotation retained. Distinct event scopes or observation windows still need separate findings.

Cluster descriptions create another representation problem. “Three clusters” can be encoded as a cluster count, an ordinary count, or a cluster rate; the event field can redundantly say “clusters” while the measurement already specifies the unit. Rows 6094, 6112, 10237 and 16674 show this. A future guide and model prompt should state which structured object owns the cluster unit and whether an explicit cluster size is essential. The scorer should accept source-equivalent forms only when they preserve the counted unit. It must distinguish *three clusters* from *three seizures*.

Counts tied to a window can be framed as a rate or a period count (rows 338, 4480 and 7615). This is often one quantitative claim represented twice. The canonical form should follow the wording and preserve the denominator; a scorer equivalence should be limited to mathematically and temporally identical readings.

### 2. Event labels are too literal in some places and crucial in others

The v0.8 scorer still requires close event-label identity. For a single negative list, gold may use the combined `events` label while the saved R8 prediction retains a literal list of absences, jerks or convulsions. Rows 3015, 5351, 7911, 8006, 8079, 8144, 8160, 8264 and several 171xx rows share a quotation but fail on this field. The **v0.8 conversion/scorer**, not necessarily the model, causes part of this residual mismatch. A canonical label for an explicitly combined absence claim would remove this artificial disagreement.

The label cannot simply be ignored. A count of *seizure days* and a count of *seizures* are different measurements even if they share the number and sentence. Rows 12314, 15745, 15766 and 17110 expose this. Likewise a rate for tonic-clonic seizures must not be attached to drop attacks (row 13513). The ideal state is a small event ontology that distinguishes event versus affected day, explicit subtype versus generic event, and broad absence lists, while treating mere wording variants as equivalent.

### 3. Some misses are genuine reading or instruction failures

Forty-three overlap pairs differ on `timing`; 31 are counts. Several historical event narratives in the 145xx, 146xx and 167xx groups were emitted as current. In clear cases the text explicitly places the event in the past. This is a prompt/example or model-reading problem, not a reason to collapse current and historical findings. The rendered R8 instructions explicitly default timing to current and require historical only when the source marks it; examples should make superseded past episodes and current status unambiguous. Some edge cases depend on whether a dated event is still the latest known event; those need reviewer adjudication.

Some extra-only predictions appear to promote context into frequency: a quiet gap between clusters (10618), “head-fog” without seizure features (8355), or a long seizure-free period embedded in a history of recurrent events (12506–12749). Some miss-only references are genuinely overlooked: explicit rates (854, 2740, 9299), bounded counts or cluster sizes (1363, 11002), and anchored absences (4956, 5040). Others are debatable gold choices, including secondary generalisation “at times” (2622), an occasional work observation (2992), vague improvement (8089), and repeated versions of a total (14146). These need domain review before treating every residual as model error.

### 4. A changed target and a conversion defect account for some disagreement

R8 was instructed under the v0.7 rule **never to merge or sum findings**. The later v0.8 reference combines same-event diary months and dated incidents. Therefore a remaining split-versus-combined mismatch is partly a target change, not proof that R8 ignored its own instructions. The v0.8 projection was intended to align the saved predictions with that changed target, but it misses year-prefixed month labels: row 9462 retains 11 monthly prediction counts and row 9496 retains 12, while each gold has one combined count. Together these rows contribute **23 extras and two misses** from a known conversion limitation. Row 15992 splits a diary count when one predicted month says “while awake”; row 16097 splits on event-label wording. Row 15982 instead combines nocturnal and daytime counts that gold keeps separate. These are implementation or policy defects in the retrospective conversion and should be fixed before using the score to judge future schema choices.

Finally, 97 misses in 33 miss-only letters follow unusable model responses with no projected predictions. They are response/replay reliability failures, not fine-grained annotation mismatch. They account for 18% of all misses. The remaining 91 misses in 78 usable miss-only letters need normal annotation review, with a prominent qualitative and seizure-free component.

## Implications for the next version

1. **Keep the v0.8 principle of one scored finding per distinct claim.** Extend it to a single seizure-free state per event scope/interval and a single cluster claim where count, rate and size are facets of the same measured unit. Do not merge different seizure subtypes, event counts with seizure-day counts, or distinct windows.
2. **Specify the canonical object before changing the prompt.** Decide how an absence interval, a broad negative list, a cluster unit and a count-in-window are represented. Give positive and counterexamples, especially for current versus historical events. The current R8 prompt still expresses the older v0.7 split rule, so saved R8 is an imperfect test of v0.8 prompt quality.
3. **Separate scorer tolerance from schema simplification.** Normalize harmless wording and source-equivalent periods, but retain clinically consequential units, scopes, status and timing. Score a source-supported paraphrase without requiring identical event strings or copied period wording.
4. **Repair the v0.8 conversion and rerun the saved-response score before comparing hypotheses.** The year-prefixed diaries alone materially inflate both error counts. Audit each repair against the source and keep the pre-repair score for reproducibility.
5. **Review disputed gold examples with a clinician/annotator.** The source-overlap index identifies candidates; it cannot decide whether vague sensations, historical generalisation, seizure-free days, or related broad and narrow absences belong in the inventory.
