## Domain‑specific rules

1. **Only count events from the confirmed epilepsy diagnosis.**  
   - Exclude events that describe non‑epileptic episodes (e.g., febrile seizures in childhood, head injuries, staring episodes that are not diagnosed as seizures, or pre‑diagnosis events that are not part of the current seizure‑frequency picture).  
   - In particular, do **not** include the very first seizures that led to a new diagnosis as a current `frequency_rate` – such statements are historical and not part of ongoing frequency.  
   - Only include events that describe the current seizure control (e.g., “seizure free”, “weekly”, “1 since previous appointment”).  
   - **Also exclude events where the evidence uses vague terms like “attacks” or “minor seizures” unless the letter explicitly labels them as epileptic seizures (e.g., “epileptic attacks”, “seizures”).** “Attacks” alone is ambiguous and should be omitted (see Example 5).

2. **Kind must match exactly:**  
   - `frequency_rate`: explicit numeric or periodic frequency (e.g., “4 to 5 times a year”, “weekly”, “1 since previous appointment”).  
   - `cluster_frequency`: a specific cluster (e.g., “a cluster of 5 seizures within two days”).  
   - `seizure_free`: explicit statement that the patient is seizure‑free (e.g., “remains seizure free”, “no further seizures”, “seizure free since…”, or a statement like “last event was more than 5 years ago” which implies current freedom).  
   - `changed`: a **qualitative** improvement or worsening (e.g., “seizures have improved”, “better controlled”, “increased”, “decreased”). Do **not** use `changed` for vague statements like “well controlled” unless they explicitly indicate a change relative to a previous state (e.g., “now well controlled” is acceptable). **Do not use `changed` for the mere emergence of a new seizure type** – a new onset is not an improvement or worsening of existing seizures.  

3. **Evidence must be an exact substring** copied verbatim from the letter. Do not paraphrase.

4. **Do not add events that are not part of the seizure‑frequency picture.**  
   - Only include each seizure type that is explicitly mentioned in the letter **using a standard medical term** (e.g., “generalised tonic clonic seizures”, “myoclonic jerks”, “absences”, “focal seizures”, “complex partial seizures”). Avoid vague descriptors like “minor seizures” – they are not acceptable seizure types and such events should be omitted (see Example 7).  
   - Do not consolidate different types into a generic “seizures” unless the letter itself does so.

5. **Preserve draft events unless the letter contradicts them.** Correct the `kind` if the draft mislabels (e.g., a `frequency_rate` for a `seizure_free` statement). Remove draft events only if they are unsupported by the letter (i.e., the letter does not contain that statement or it is non‑epileptic).  

6. **Historical frequency statements** – Include a `frequency_rate` only if it describes the current or ongoing pattern. For example, “roughly two seizures per year” when the last seizure was recent enough that the rate still applies is acceptable (Example 4). But “used to happen weekly” with no current recurrence is not a current frequency and should be omitted (Example 6). Similarly, “4 more attacks” is ambiguous and should be omitted (Example 5).

7. **Output strictly one JSON object** with key `"events"` containing the corrected list. No extra text or markdown.
