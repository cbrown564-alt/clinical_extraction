=== diagnosis ===
You are given a clinical letter text. Your task is to extract all distinct clinical facts from the letter and return them as a JSON object matching the schema below. The facts belong to one of four families: `diagnosis`, `seizure_frequency`, `prescription`, or `investigation`. Follow these rules:

- **Diagnosis facts**: Epilepsy type, seizure types, and any epilepsy‑related comorbid conditions (e.g., “focal epilepsy”, “generalised tonic‑clonic seizures”, “temporal‑lobe‑seizure”). Do **not** emit non‑epilepsy diagnoses (e.g., ischaemic heart disease, low mood, stress). Use short canonical concept names (e.g., “drug‑refractory‑epilepsies”, not “Drug refactory focal epilepsy”). Always include a `negation` field: `"affirmed"` if the diagnosis is present, `"negated"` if explicitly ruled out.

- **Seizure frequency facts**: For every seizure type mentioned, emit a fact with the family `seizure_frequency`. The `concept` field must encode both the seizure type and its current state, using the following formats:
  - **Active rate**: `"<canonical‑seizure‑type>: active‑rate (NumberOfSeizures=<number>, TimePeriod=<unit>)"`  
    Example: `"tonic‑clonic‑seizure: active‑rate (NumberOfSeizures=1, TimePeriod=Month)"`
  - **Changed frequency** (more/fewer/improved/worse): `"<canonical‑seizure‑type>: changed (<direction>)"`  
    Example: `"tonic‑clonic‑seizures: changed (frequent)"` or `"seizure: changed (decreased)"`
  - **Seizure‑free**: `"<canonical‑seizure‑type>: seizure‑free"`  
    Do **not** default every mention to active‑rate. A reported improvement or worsening is a distinct `changed` fact.

- **Prescription facts**: Each medication with its dose and frequency. Use canonical drug names (e.g., “Carbamazepine”, not “Tegretol”). Format: `"<drug> <dose> x<times‑per‑day>"` (e.g., `"Carbamazepine 200mg x1"`). Family: `prescription`.

- **Investigation facts**: Each test performed and its result (if mentioned). Use short canonical names: `"EEG (<finding>)"`, `"MRI (<finding>)"`. If no result is given, use `"EEG (Unknown)"`. Family: `investigation`.

**General rules**:
- Always ground every fact with an **exact substring** copied from the letter as the `evidence` field.
- **De‑duplicate**: emit each distinct concept only once, even if mentioned multiple times.
- For diagnosis facts only, include the `negation` field. For other families, omit `negation`.
- Return **exactly one JSON object** with a field `"clinical_facts"` containing a list of fact objects. Each object must have at least `"concept"`, `"evidence"`, and `"family"`. Use the following schema:

```json
{
  "clinical_facts": [
    {
      "concept": "short canonical concept (with state if applicable)",
      "evidence": "exact substring from the letter",
      "family": "diagnosis | seizure_frequency | prescription | investigation",
      "negation": "affirmed | negated"   // only for diagnosis family
    }
  ]
}
```

Do not use markdown. Output only the JSON.

Examples of correct concept formatting (from gold standards):
- Diagnosis: `"generalised epilepsy"`, `"focal epilepsy"`, `"generalised‑tonic‑clonic‑seizures"`, `"temporal‑lobe‑seizure"`
- Seizure frequency: `"tonic‑clonic‑seizures: changed (frequent)"`, `"seizure: changed (decreased)"`, `"tonic‑clonic‑seizure: active‑rate (NumberOfSeizures=1, TimePeriod=Month)"`, `"focal‑to‑bilateral‑convulsive‑seizures: active‑rate (NumberOfSeizures=1)"`
- Prescription: `"lamotrigine 100mg x1"`, `"Carbamazepine 200mg x2"`, `"sodium valproate 400mg x2"`
- Investigation: `"EEG (generalised spike and wave)"`, `"MRI (normal)"`, `"EEG (Unknown)"`
