Scratch · explainer prototypes

Make the system feel tangible — not like a nicer file tree.

The first prototypes (Map / Ladder / Console) orient you, but a newcomer can almost reconstruct them by reading folders and docs. The second wave asks a harder question: what becomes obvious only when you watch mechanism, difference, and custody?

Wave 2 — mechanism prototypes

Letter journey

Scrub a synthetic clinic letter through a real method. The clinical claim morphs on screen; the paper pulses when a stage rewrites it. Play mode is a filmstrip of mechanism.

time, transformation, and which stage actually moved the answer

Method X-ray

Three rails for one task. Block colour is effect class, not folder. Red outlines mark stages that exist only on the densest path — the repair families hybrid adds over LLM-only.

the delta between methods as a single glanceable object

Answer custody

Treat the answer as a token that moves between Model, Rules, and Scorer. Handoffs light up. The story under the diagram is why LLM-only stays wrong and hybrid recovers.

who holds the clinical claim at each moment

Further pathways worth considering

Machine room

CLI tokens as physical levers on a visible apparatus. Flipping --method rewires pipes in view — stages dock and undock. Stronger than Console’s token inspector because the machine itself changes shape.

command → topology, as a spatial rewrite

Two-task geography

Not a tree: two islands (Gan / ExECT) in a shared sea (core, contracts), with sediment underwater. Zoom from archipelago → harbour → quay (stage) → bolt (symbol). Size by clinical responsibility, not LOC alone.

shared machinery vs task-private meaning, as place

Attribution theater

Close-up on one repair event (e.g. typical-over-YTD). Split view: model’s chosen event vs rule’s winning event, with quoted evidence from the letter. One mechanism, fully staged.

why a specific rule fired, in human narrative form

Six-lane race

All six methods on the same letter, synchronized scrub. Wrong lanes fade; the recovering lane stays lit. Makes the research claim — component attribution — visually inevitable.

comparative mechanism across the whole selected set

Sediment sonar

Selected path as a bright spine; agentic/GEPA/experiments as echo returns below. Useful only if the moral is “what not to read first,” not a second file browser.

deliberate non-path mass as negative space
